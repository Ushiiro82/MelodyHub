# MelodyHub

MelodyHub — это приложение, которое позволяет пользователям искать музыку, а также разделять mp3 файлы на дорожки, с возможностью их сохранения и прослушивания.

## Описание

MelodyHub предоставляет удобный интерфейс для прослушивания музыки онлайн. Пользователи могут:

- **Искать и просматривать треки**
- **Разделять mp3 файлы на дорожки:
  мелодия, бас, ударные, вокал**
- **Также присутствует возможность прослушивания и сохранения каждой дорожки по отдельности**

### Технологии

Приложение полностью написано на python 3.10
Все необходимые зависимости указаны в файле requirements.txt
